# Simple Ticket Management System

A beginner-friendly PHP + MySQL final project.

## Features
- Submit a support ticket
- Automatically generate a Ticket ID
- Track a ticket by ID
- Admin login
- Admin dashboard
- View ticket details
- Update ticket status
- MySQL CRUD operations
- Responsive modern UI

## XAMPP Setup
1. Copy this folder to `C:/xampp/htdocs/`
2. Start Apache and MySQL.
3. Open `http://localhost/phpmyadmin`
4. Import `database.sql`
5. Open `http://localhost/simple-ticket-management-system/`
