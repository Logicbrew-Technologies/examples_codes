FULL PHP PORTFOLIO

Files:
- index.php  -> Complete PHP + HTML portfolio
- style.css  -> Complete styling
- images/    -> Put a profile.jpg image here

Run using XAMPP:
1. Copy this folder into C:\xampp\htdocs\
2. Start Apache.
3. Open: http://localhost/portfolio_full/

Edit the PHP variables at the top of index.php to customize the portfolio.
