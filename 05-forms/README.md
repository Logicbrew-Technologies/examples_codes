# Forms

Try the examples in this order:

1. `01-simple-form.php` - Create a basic HTML form and read POST data.
2. `02-form-processing.php` - Use submitted data with PHP logic.
3. `03-form-database.php` - Insert submitted form data into MySQL.

Before running `03-form-database.php`, import `03-sql/database.sql` into phpMyAdmin.
